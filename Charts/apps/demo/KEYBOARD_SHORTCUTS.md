# Keyboard Shortcuts Reference

## Global Shortcuts

| Shortcut | Action | Description |
|----------|--------|-------------|
| **⌘K** (Mac) / **Ctrl+K** (Windows) | Open Hub | Opens the Hub panel for search and quick access |
| **Esc** | Close Panel | Closes any open panel or deselects active tool |
| **E** | Toggle Eraser | Switches to/from eraser mode |

## Category Shortcuts

Activate the last-used tool in each category:

| Shortcut | Category | Example Tool |
|----------|----------|--------------|
| **L** | Levels | Horizontal Line, Horizontal Ray, etc. |
| **T** | Trend | Trend Line, Trend Angle, etc. |
| **S** | Structure | Fibonacci Retracement, Extension, etc. |
| **Z** | Zones | Supply/Demand Zones, Order Blocks, etc. |
| **F** | Overlays | Fibonacci Channel, VWAP, etc. |
| **P** | Patterns | XABCD, Head & Shoulders, etc. |
| **R** | Plan | Long Position, Multi-Target, etc. |
| **M** | Measure | Price Range, Combined Range, etc. |
| **A** | Annotate | Text, Callout, Brush, etc. |

## How It Works

1. **Single Key Press**: Activates the most recently used tool in that category
2. **Panel Memory**: Each category remembers your last selection
3. **No Input Interference**: Shortcuts are disabled when typing in search fields
4. **Platform Aware**: Automatically uses ⌘ on macOS, Ctrl on Windows/Linux

## Tips

- Use **⌘K** to quickly search for any tool without moving your mouse
- Press the same category key repeatedly to cycle through your workflow
- Category shortcuts work even when panels are closed
- Customize which tool is "last-used" by selecting from the panel

## Examples

**Fast Workflow**:
1. Press **L** → Draws horizontal line (last-used Levels tool)
2. Press **T** → Draws trend line (last-used Trend tool)
3. Press **P** → Draws XABCD pattern (last-used Pattern tool)

**Search Workflow**:
1. Press **⌘K** → Opens Hub
2. Type "fib" → Shows Fibonacci tools
3. Press **Enter** → Selects first result
4. Next time, press **S** to reuse that Fibonacci tool
