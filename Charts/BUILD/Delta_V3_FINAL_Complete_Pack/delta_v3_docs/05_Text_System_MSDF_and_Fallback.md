# Text System (MSDF + Fallback) — V3 Blueprint
**Goal:** stable numeric labels + robust international text support without atlas blowups.

---

## 1) Two-lane text system
Lane A: **GPU MSDF** (numbers/Latin, axis labels, HUD microtext)  
Lane B: **Canvas2D/DOM** (complex scripts, long annotations, editing/IME)

---

## 2) MSDF lane (GPU)

### 2.1 Assets
- Ship a prebaked atlas for digits + Latin + punctuation.
- Include glyph metrics (advance, bearing, uv rect) and kerning if needed.

### 2.2 Runtime glyph pages
- For extra glyphs, allocate dynamic atlas pages.
- Insert glyphs rarely; never in the hot path of pointer move.
- Insertions happen in a background task with a cap per second.

### 2.3 GPU rendering pipeline
- Glyph quads generated by CPU layout engine.
- Vertex buffer contains:
  - position (x,y)
  - uv (u,v)
  - color
- Fragment shader samples MSDF and computes edge coverage via derivatives.

### 2.4 Stability rules
- Baseline snapping in physical pixels
- Label hysteresis: don’t relayout on micro changes
- Optional scale quantization during kinetic zoom

---

## 3) Fallback lane (Canvas2D / DOM)

### 3.1 When to use fallback
- CJK and complex scripts
- Text editing (caret, selection, IME)
- Long paragraphs / annotation notes

### 3.2 Composition
Options:
- draw fallback text into a separate overlay canvas
- or render as DOM elements positioned over the chart

Rules:
- keep fallback lane isolated so it doesn’t force full chart redraw
- synchronize transforms with camera changes

---

## 4) Shaping roadmap
- V3.0: numeric/Latin axis labels with simple layout
- V3.1+: add shaping via HarfBuzz (WASM) for correctness across scripts
- Cache shaped runs aggressively (axis labels repeat)

---

## 5) Memory budgets
- set a max atlas memory per tier
- when over budget:
  - evict least-used dynamic pages
  - fall back to Canvas2D for rare glyphs

---

## 6) Testing
- Golden tests: axis labels at multiple zoom levels
- Jitter test: pan slowly and ensure labels don’t shimmer
- Mixed scripts test: Latin + CJK + emoji in annotations
