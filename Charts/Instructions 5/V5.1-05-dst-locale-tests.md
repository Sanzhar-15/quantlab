# V5.1 Prompt 05 - DST + Locale Regression Tests

Goal
- Prevent time formatting regressions across DST, timezone, and locale.

Constraints
- Additive tests only.
- No changes to core formatting behavior unless required for correctness.

Deliverables
- DST/locale test pack covering time axis and crosshair formatting.

Steps
1) Create tests that simulate timestamps across DST boundaries.
2) Test UTC vs local time zone formatting.
3) Test locale-specific formatting differences with explicit formatters.

Acceptance
- Formatting remains consistent and predictable across DST boundaries.
- Tests cover at least two timezones and two locales.

Tests
- New unit tests for formatter behavior.
