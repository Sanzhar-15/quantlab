# V5.3 Prompt 07 - Series API + Data Models

Goal
- Expand series APIs and data models to support OHLC and histogram types.

Constraints
- Additive only; no breaking API changes.
- Default behavior must remain unchanged for existing line series.

Deliverables
- Add new series creation APIs (e.g., addCandlestickSeries, addBarSeries, addHistogramSeries, addAreaSeries, addBaselineSeries).
- Add new data model types for OHLC and histogram.
- Update docs to reflect new API additions.

Steps
1) Extend API types to include OHLC + histogram data shapes.
2) Add new series interfaces for each type (additive).
3) Wire series registration in renderer entry points.
4) Update docs and current state summary.

Acceptance
- Existing line charts unchanged.
- New series APIs compile (even if rendering is stubbed for now).

Tests
- Type-level or unit tests for new API shapes.
