# V5.5 Prompt 01 - Test Strategy Audit

Goal
- Lock a complete V5.5 test matrix and coverage targets.

Constraints
- Additive only; do not remove existing tests.

Deliverables
- V5.5 test matrix (unit, integration, visual, perf, fuzz).
- Explicit coverage gaps and required fixes.

Steps
1) Inventory existing tests and map coverage to V5.1–V5.4 features.
2) Identify missing test categories (series types, crosshair modes, chart types).
3) Define coverage targets and required additions.

Acceptance
- Test matrix approved and gap list documented.

Tests
- None (planning + docs).
