# V5.1 Prompt 04 - Deterministic Export + Formatting Stability

Goal
- Make PNG export deterministic across DPR, timezone, and font variations.

Constraints
- Do not change default visual output for interactive rendering.
- Export determinism must be additive and opt-in safe.
- Export rendering must be isolated from live chart state.

Deliverables
- Deterministic export path in `chart.exportPng`.
- Tests for deterministic output across DPR/timezone.

Steps
1) Add an isolated export render path:
   - No mutation of live chart state.
   - Deterministic render order and settings.
2) Normalize export rendering:
   - Normalize DPR and font metrics for export path.
   - Stabilize time formatting inputs (timezone, locale).
   - Use a fixed export font fallback if needed for cross-machine stability.
3) Add tests that compare output hashes across multiple DPR/timezone settings.

Acceptance
- Exported PNG is stable for the same input across environments.
- Interactive rendering is unchanged.

Tests
- Add visual or hash-based tests for export determinism.
