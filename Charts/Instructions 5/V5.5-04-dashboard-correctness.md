# V5.5 Prompt 04 - Dashboard Correctness

Goal
- Validate behavior on dashboard-scale deployments.

Constraints
- Offscreen charts must not render when idle.
- Shared RAF must not starve visible charts.

Deliverables
- Dashboard correctness test (12–20 charts, visibility pause, sync groups).
- Assertions for offscreen inactivity and interaction latency.

Steps
1) Build dashboard test harness with multiple charts.
2) Validate offscreen charts remain idle.
3) Validate sync groups do not amplify render workload.

Acceptance
- Dashboard test passes without regressions.

Tests
- New integration test or perf harness scenario.
