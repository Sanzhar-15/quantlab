# V5.2 Prompt 07 - Conflation for Deep Zoom

Goal
- Reduce draw cost for massive datasets when zoomed far out while preserving shape.

Constraints
- Conflation must be opt-in or auto-gated by pixel density.
- Must not change visuals at normal zoom levels.

Deliverables
- Conflation path integrated with decimator/LOD.
- Threshold tuning to keep visual fidelity.

Steps
1) Add conflation stage when data density exceeds pixel threshold.
2) Ensure conflation respects gap semantics.
3) Validate output shape against raw data at deep zoom.

Acceptance
- Scenario C/D p95 frame time improves.
- Visual fidelity remains intact.

Tests
- Visual regression at deep zoom + perf scenario C.
