# V5.2 Prompt 08 - Memory Policy Enforcement

Goal
- Keep memory bounded under long streaming sessions.

Constraints
- Must not affect visible data fidelity.
- Must not regress performance on short sessions.

Deliverables
- Raw retention window + LOD-only beyond range.
- Rehydrate strategy if DataProvider is present.

Steps
1) Implement raw retention policy with LOD-only outside window.
2) Add rehydrate behavior on zoom-in if provider available.
3) Instrument memory and retention metrics.

Acceptance
- Memory remains flat in long streaming scenario.
- No visible degradation in normal zoom ranges.

Tests
- Perf scenario E + memory sampling validation.
