# V5.2 Prompt 04 - Worker/Offscreen Stability

Goal
- Ensure worker rendering is stable, opt-in, and consistent with main-thread output.

Constraints
- Worker must remain opt-in by import.
- Must not regress fallback behavior.

Deliverables
- Stable worker initialization and resize handling.
- Consistent output between worker and main.

Steps
1) Audit worker entry + initialization for race conditions.
2) Ensure resize and theme changes propagate reliably.
3) Validate fallback behavior when worker is unavailable.

Acceptance
- No visual differences between worker and main rendering.
- Worker opt-in remains intact.

Tests
- Run demo in both `seriesRenderer=main` and `seriesRenderer=worker`.
