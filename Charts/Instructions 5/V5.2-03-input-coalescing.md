# V5.2 Prompt 03 - Input Pipeline Coalescing

Goal
- Reduce input latency by coalescing pointer/wheel events per frame.

Constraints
- No breaking behavior changes.
- Maintain overlay-only pointermove invariant.

Deliverables

- Reduced GC from input handling.

Steps
1) Coalesce pointermove/wheel events into a single per-frame intent.
2) Ensure drag updates remain responsive and accurate.
3) Add lightweight instrumentation counters for input coalescing if needed.

Acceptance
- Pointer/drag p95 latency improves.
- No interaction regressions in pan/zoom.

Tests
