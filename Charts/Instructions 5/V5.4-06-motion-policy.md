# V5.4 Prompt 06 - Motion Policy (Minimal + Meaningful)

Goal
- Define and apply minimal motion rules that enhance clarity.

Constraints
- No animations that block interaction.
- No excessive motion that distracts.

Deliverables
- Motion rules for tooltip/crosshair transitions.
- Animation timings documented.

Steps
1) Define allowed animations (fade, subtle slide).
2) Ensure all animations are optional and non-blocking.
3) Validate interaction latency unchanged.

Acceptance
- Motion improves clarity without distraction.
- No perf regressions.

Tests
- Visual regression on animated states.
