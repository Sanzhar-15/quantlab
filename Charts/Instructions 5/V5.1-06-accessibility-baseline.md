# V5.1 Prompt 06 - Accessibility Baseline

Goal
- Add minimal but solid accessibility and keyboard control support.

Constraints
- Must not regress performance or interaction latency.
- Additive-only behavior.
- Keyboard handling must only activate when chart is focused.

Deliverables
- Keyboard navigation for pan/zoom/crosshair.
- Focus ring and basic ARIA labels on chart container.
- Documentation note in V5 contract.

Steps
1) Add keyboard handlers for:
   - Arrow keys pan.
   - +/- zoom.
   - Esc clears crosshair.
2) Ensure handlers only run when chart has focus:
   - `tabIndex=0` on container.
   - Only preventDefault for handled keys.
3) Add focus styles for chart container.
4) Add ARIA labels for chart container and primary controls.
5) Update docs to mention accessibility baseline.

Acceptance
- Keyboard controls work only when focused and do not hijack page scroll.
- Focus styling visible but unobtrusive.
- No perf regressions.

Tests
- Add basic interaction tests for keyboard events if feasible.
