# V5.1 Prompt 03 - Data Integrity Policy + Tests

Goal
- Define and enforce strict data integrity rules for all ingestion paths.

Constraints
- Additive options only; no breaking defaults.
- Must preserve current behaviors unless explicitly gated by new options.

Deliverables
- Update data integrity policy in code and documentation.
- Unit tests for out-of-order, duplicates, NaN/Infinity, and null gaps.

Steps
1) Define policy fields (configurable) in data provider options:
   - out-of-order: reject or drop.
   - duplicates: replace or ignore.
   - NaN/Infinity: treat as gaps.
2) Enforce policy in all ingestion paths:
   - `DataStore`
   - `ChunkedDataStore`
   - `DataProvider` updates (append, appendBatch, updateLast, reset)
3) Add unit tests:
   - Out-of-order handling for append/appendBatch.
   - Duplicate timestamp handling.
   - NaN/Infinity handling.
   - Null gap stability for rendering.

Acceptance
- Default behavior remains unchanged.
- Tests pass and cover all policy branches.

Tests
- Unit tests for data store ingestion policy.
