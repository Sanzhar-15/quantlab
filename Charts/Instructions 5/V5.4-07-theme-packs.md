# V5.4 Prompt 07 - Theme Packs (Beyond LC)

Goal
- Ship curated theme packs that are distinct but readable.

Constraints
- Themes must be opt-in; no default regressions.
- Export PNG must use theme tokens.

Deliverables
- 2–3 curated theme presets (dark/neutral/light).
- Theme presets documented.

Steps
1) Define theme presets using V5 tokens.
2) Ensure exports use the same tokens.
3) Validate readability and contrast for each preset.

Acceptance
- Themes are visually distinct and readable.
- Export matches theme styling exactly.

Tests
- Visual regression for each theme preset.
