# V5.5 Prompt 06 - Accessibility + UX Compliance

Goal

Constraints
- Additive only; no visual regressions.

Deliverables

Steps
1) Validate contrast thresholds for all themes.
2) Verify keyboard pan/zoom/crosshair still work.
3) Document any accessibility tradeoffs.

Acceptance
- Contrast and keyboard controls pass validation.

Tests
