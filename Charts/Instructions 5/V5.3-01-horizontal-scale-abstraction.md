# V5.3 Prompt 01 - Horizontal Scale Abstraction

Goal
- Introduce a pluggable horizontal (X) scale interface without changing current time-scale behavior.

Constraints
- Additive only; no breaking API changes.
- Existing time-based charts must render identically.

Deliverables
- Horizontal scale abstraction with default time scale implementation.
- No behavioral changes to existing charts.

Steps
1) Define a horizontal scale interface (time/numeric/custom).
2) Implement the current time scale as the default implementation.
3) Route all X-axis lookups through the abstraction.

Acceptance
- Existing charts are visually identical.
- No perf regressions in A–F scenarios.

Tests
- Visual regression for time-based charts.
