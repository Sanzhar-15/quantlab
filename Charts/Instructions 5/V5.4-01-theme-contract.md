# V5.4 Prompt 01 - Theme Contract + Schema Validation

Goal
- Define V5 theme token contract and enforce schema validation.

Constraints
- Additive only; no default visual regressions.
- Missing tokens must fall back safely.

Deliverables
- Theme token schema + validation.
- Token audit and fallback mapping.

Steps
1) Define required V5 theme tokens (grid hierarchy, axis text, tooltip, crosshair, focus band, series palette).
2) Add schema validation with defaults for missing tokens.
3) Audit current theme usage to ensure all tokens are consumed consistently.

Acceptance
- No visual changes unless new tokens are explicitly applied.
- Missing tokens do not break rendering.

Tests
- Unit tests for token validation and fallback.
