# Megaudit-2 A4-C2: pinned minimum runtime dependencies for the qviz
# daemon. The extension host spawns this package as a long-lived Python
# subprocess; if the user's venv is missing these or has them at versions
# the daemon can't use, the startup probe (`_check_duckdb_version`) and
# the package imports will fail LOUDLY with stderr that the extension
# surfaces as `daemonStatus: unavailable`.
#
# duckdb: 1.5.1 is the first release with `to_arrow_table` that starts
# (1.5.0 aborts at start); DuckDB 1.5 needs Python >= 3.10. pandas and
# numpy are imported when the daemon starts (qviz.presets, qviz.decimate);
# no floor below the versions the tests ran on has been measured for them.
#
# Upper bounds are intentionally open: we want bug fixes in patch
# releases to land without a coordinated requirements bump. If a future
# release breaks compatibility, add an upper-bound constraint here
# along with a release-note pointer.
duckdb>=1.5.1
pyarrow>=10.0.0
pandas
numpy
