## What to look for

### Correctness (highest priority)

1. **statrs API verification:** `ChiSquared::new(df)` and
   `FisherSnedecor::new(df1, df2)`. PDF/CDF/inverse_cdf calls. Verify
   each impl uses the right method.
2. **`statrs`'s `sf(x)` for CHISQ.DIST.RT:** uses `dist.sf(x)`
   (survival function) directly for numerical stability vs
   `1 - dist.cdf(x)`. Matches IronCalc. Verify the `sf` import is in
   scope (via `ContinuousCDF` trait — already imported).
3. **F.DIST.RT uses `1 - dist.cdf(x)` NOT `sf`.** IronCalc divergence:
   CHISQ.DIST.RT uses sf, F.DIST.RT uses 1-cdf. Verify our impls match
   this asymmetric pattern.
4. **Domain checks match IronCalc canon line-by-line:**
   - CHISQ.DIST: `x >= 0`; `df.trunc()` in `[1, 10^10]`. 3 args.
   - CHISQ.DIST.RT: same domain. 2 args.
   - CHISQ.INV: `0 <= p <= 1` INCLUSIVE; `df` in `[1, 10^10]`. 2 args.
   - CHISQ.INV.RT: same domain as CHISQ.INV. 2 args.
   - F.DIST: `x >= 0`; `df1.trunc() >= 1`; `df2.trunc() >= 1`. NO upper
     ceiling on df1/df2. 4 args.
   - F.DIST.RT: same domain. 3 args.
   - F.INV: `0 <= p <= 1` INCLUSIVE; `df1 >= 1`; `df2 >= 1`. 3 args.
   - F.INV.RT: **`p <= 0.0 || p > 1.0`** — lower-strict, upper-inclusive.
     IronCalc divergence from F.INV / CHISQ.INV / CHISQ.INV.RT.
   - Verify each impl matches.
5. **`MAX_CHISQ_DEGREES_OF_FREEDOM = 10^10` ceiling** — only for
   CHISQ.*, not F.*. Matches IronCalc (`MAX_DEGREES_OF_FREEDOM` is
   defined in `chisq.rs` but not `fisher.rs`).
6. **Negative-result guards** — chi-squared and F are non-negative
   random variables; any negative `x` from inverse_cdf or any negative
   `1 - cdf` signals fp anomaly. Verify guards in CHISQ.DIST.RT,
   CHISQ.INV, CHISQ.INV.RT, F.DIST.RT, F.INV, F.INV.RT.
7. **`finite_or_num` routing:** verify cdf/pdf paths use
   `finite_or_num`. Inverse paths (which need the negative-result
   guard) use explicit `is_finite() || result < 0.0` check then
   `Value::number(result)`.
8. **Coercion:** all numeric args via `to_number_strict`. cumulative
   flag via `to_logical`. Same divergences as W5-D-1/D-2.
9. **Arity:** strict — wrong count → `#VALUE!` (NOT `#N/A`). Verify
   under AND over arity per W5-D-2.1 LOW-O-1 closure pattern.
10. **`.expect()` justification** for `chi_squared_with` /
    `fisher_snedecor_with`: pre-check + NaN-rejecting `to_number_strict`
    guarantee statrs constructor succeeds. Verify the chain holds.
11. **Anchor values:**
    - CHISQ.DIST(2, 2, TRUE) = 1 - e^-1 (closed-form, exponential(1/2)
      CDF at x=2).
    - CHISQ.DIST(0, 2, FALSE) = 0.5 (df=2 PDF at 0).
    - CHISQ.INV(0.95, 1) ≈ 3.841459 (classic chi-squared critical).
    - CHISQ.INV(0.5, 2) = 2*ln(2) (df=2 closed-form).
    - F.DIST(1, 10, 10, TRUE) = 0.5 (symmetric F(n,n)).
    - F.INV(0.5, 10, 10) = 1.0 (median for symmetric F(n,n)).
    - F.INV(0.95, 5, 10) = `3.3258345304130046` (statrs's
      Newton-Raphson value, ~5e-7 off true math `3.325835018413022`).
      **VERIFY THIS DIVERGENCE IS DOCUMENTED.**
12. **F.INV.RT lower-strict boundary:** verify the test
    `f_inv_rt_at_zero_prob_is_num_error` pins this divergence from
    F.INV (which accepts p=0).

### IronCalc divergences
