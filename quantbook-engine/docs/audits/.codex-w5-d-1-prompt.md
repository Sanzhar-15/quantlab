## What to look for

### Correctness

1. **statrs API verification:** `Normal::new(mean, sd)`, `cdf(x)`, `pdf(x)`, `inverse_cdf(p)`. Verify the impl uses the right methods.
2. **Domain checks match Excel/IronCalc canon:**
   - NORM.DIST: `sd > 0` strict (else `#NUM!`); ours checks `sd <= 0.0`. ✓ verify.
   - NORM.INV: `0 < prob < 1` strict (endpoints excluded). Ours: `p <= 0.0 || p >= 1.0`. ✓
   - NORM.S.INV: same `0 < prob < 1`. ✓
3. **Error class:** non-finite results (Inf / NaN from statrs at extreme inputs) → `#NUM!` via `finite_or_num`. Verify all 4 fns route through.
4. **Coercion:**
   - All numeric args via `to_number_strict` (Text → `#VALUE!`).
   - `cumulative` flag via `to_logical` (Number → 0/non-0 → bool; Text "true"/"false" → bool; else `#VALUE!`).
5. **Arity:** strict — wrong count → `#N/A`. Verify against IronCalc's `new_args_number_error`.
6. **Anchor values vs LibreOffice 7.6:**
   - NORM.DIST(0,0,1,TRUE) = 0.5 ✓
   - NORM.DIST(0,0,1,FALSE) = 1/√(2π) ≈ 0.39894228... ✓
   - NORM.DIST(2,1,2,TRUE) ≈ 0.691462461274013 (claim)
   - NORM.DIST(1,0,1,FALSE) ≈ 0.241970724519143 (claim)
   - NORM.S.DIST(1,TRUE) ≈ 0.841344746068542 (claim)
   - NORM.S.DIST(-2,TRUE) ≈ 0.022750131948179 (claim)
   - NORM.INV(0.975,0,1) ≈ 1.95996398454005 (claim)
   - Verify these are correct LibreOffice values.

### IronCalc divergences

7. **IronCalc returns `Error::ERROR` (= `#ERROR!`) for statrs construction failure; we map to `#NUM!`.** Is this divergence acceptable? Excel canon for "construction failed" — IronCalc's `#ERROR!` is non-standard. Our `#NUM!` is more Excel-canonical. Verify and document.
8. **IronCalc's `get_number_no_bools`** vs our `to_number_strict`: IronCalc REJECTS Boolean args for `x`/`mean`/`sd`/`prob`; ours ACCEPTS Boolean as 0/1. Excel canon: Boolean coerces to 0/1 in numeric context, so our behavior is correct; IronCalc's stricter rejection is a divergence. Document.
9. **CONFIDENCE.NORM / CONFIDENCE.T** also in IronCalc's normal.rs — not yet ported in W5-D-1. Confirm these are intentionally out of scope for this commit.
