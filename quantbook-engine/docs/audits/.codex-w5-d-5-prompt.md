## What to look for

### Correctness (highest priority)

1. **statrs API verification:**
   - `statrs::distribution::{Gamma, Beta}` — `cdf`, `pdf`,
     `inverse_cdf`.
   - `statrs::function::gamma::{gamma, ln_gamma}` — closed-form gamma
     and log-gamma functions (NOT distribution-backed for GAMMA /
     GAMMALN themselves).
   - CONFIDENCE.* reuse W5-D-1 `standard_normal()` + W5-D-2
     `students_t_with`.
2. **Shape-scale vs shape-rate parameterization** for Gamma: Excel
   passes shape (`alpha`) and scale (`beta`); statrs's `Gamma::new`
   takes shape-rate. Helper `gamma_dist_with(alpha, scale)` does
   `rate = 1.0 / scale` conversion. Verify.
3. **Beta variadic 4-6 args**: `[A, B]` bounds default to `[0, 1]`.
   Transforms via `t = (x - A) / (B - A)`. PDF scaled by `1/(B - A)`
   per Jacobian. Verify both transformations.
4. **BETA.INV variadic 3-5 args**: `0 < p < 1` STRICT both ends
   (matches IronCalc — note IronCalc canon comment at line 174 says
   "p==0 or p==1 are actually valid inputs" but the impl rejects;
   we follow the impl). Returns `A + t * (B - A)`.
5. **CONFIDENCE.T `#DIV/0!` divergence**: for `size < 2`, returns
   `#DIV/0!` (NOT `#NUM!`). Only fn in distribution_fns returning
   `#DIV/0!`. Matches IronCalc + Excel canon.
6. **Size truncation divergence**: CONFIDENCE.NORM uses `.floor()`,
   CONFIDENCE.T uses `.trunc()`. Matches IronCalc. Verify both.
7. **GAMMA negative-integer poles**: rejects `x < 0.0 && x.floor() ==
   x` per IronCalc. Verify.
8. **GAMMA(0) = +Inf → #NUM!**: `finite_or_num` routes via the
   finite-result guard.
9. **GAMMALN(0) = +Inf → #NUM!**: same path.
10. **Domain checks match IronCalc canon line-by-line:**
    - GAMMA: 1 arg. Reject negative integers.
    - GAMMA.DIST: 4 args. `x >= 0`, `α > 0`, `β > 0` STRICT.
    - GAMMA.INV: 3 args. `0 <= p <= 1` INCLUSIVE.
    - GAMMALN / GAMMALN.PRECISE: 1 arg. `x >= 0`.
    - BETA.DIST: 4-6 args. `α > 0`, `β > 0`, `A < B`, `A <= x <= B`.
    - BETA.INV: 3-5 args. `0 < p < 1` STRICT, `α > 0`, `β > 0`,
      `A < B`.
    - CONFIDENCE.NORM: 3 args. `0 < α < 1`, `σ > 0`, `size.floor() >=
      1`.
    - CONFIDENCE.T: 3 args. `0 < α < 1`, `σ > 0`, `size.trunc() >= 2`
      (`#DIV/0!` else).

### Anchor values

11. Verify closed-form claims:
    - GAMMA(1) = 1, GAMMA(5) = 24, GAMMA(0.5) = √π,
      GAMMA(-0.5) = -2√π.
    - GAMMA.DIST(1, 1, 1, TRUE) = 1 - e⁻¹ (α=1 reduces to exponential).
    - GAMMA.INV(0.5, 1, 1) = ln(2) (closed-form inverse).
    - GAMMALN(1) = 0, GAMMALN(4) = ln(6), GAMMALN(0.5) = 0.5·ln(π).
    - BETA.DIST(0.5, 1, 1, TRUE) = 0.5, PDF(0.5) = 1 (uniform).
    - BETA.DIST(5, 1, 1, FALSE, 0, 10) = 0.1 (U(0,10) PDF).
    - BETA.INV(0.5, 1, 1) = 0.5, BETA.INV(0.7, 1, 1, 0, 10) = 7.
    - CONFIDENCE.NORM(0.05, 1, 1) ≈ 1.959963984540054 (z_0.975).
    - CONFIDENCE.T(0.05, 1, 10) — **statrs-internal value**
      `0.7153569059706643` (statrs's Newton-Raphson approximate
      diverges from true math `0.71531056...` per W5-D-3 self-
      consistent-pin pattern). Verify.
