## What to look for

### Correctness

1. **Math kernel** — `compute_covariance(xs, ys, divisor_offset)`:
   - Computes `mean_x = sum_x/n`, `mean_y = sum_y/n` in a first pass.
   - Computes `sum_prod = Σ(x_i - mean_x)(y_i - mean_y)` in a second pass.
   - Returns `sum_prod / (n - divisor_offset)`.
   - Verify both passes use the same xs/ys, no off-by-one.
2. **Population divisor** — COVARIANCE.P passes `divisor_offset = 0.0`.
   `cov = sum_prod / n`. Requires `n >= 1` (returns `#DIV/0!` otherwise).
3. **Sample divisor** — COVARIANCE.S passes `divisor_offset = 1.0`.
   `cov = sum_prod / (n-1)`. Requires `n >= 2` (else `#DIV/0!`).
4. **Pair-collection** — both fns delegate to existing `collect_xy_pairs`
   (W5-179 helper). Verify error class for shape mismatch (`#VALUE!`
   per engine convention vs IronCalc/Microsoft `#N/A` — already
   documented engine-wide divergence; ok).
5. **Result sanitization** — uses `coercion::sanitize_f64` per the
   CORREL pattern. NaN / Inf → `#NUM!`.
6. **Anchor verification** — closed-form math:
   - `covariance_p_perfect_positive`: x=[1,2,3,4], y=2x → cov_p=2.5.
   - `covariance_p_perfect_negative`: x=[1,2,3,4], y=-2x → cov_p=-2.5.
   - `covariance_s_perfect_positive`: same x,y; cov_s=10/3.
   - `covariance_s_microsoft_example`: data1=[3,2,4,5,6],
     data2=[9,7,12,15,17] → cov_s=6.5. Verify against Microsoft
     COVARIANCE.S support page.
7. **`covariance_s_population_relationship`** — pin algebraic
   `cov_s = cov_p · n/(n-1)`. Verify this holds for any n>1.

### Edge cases

8. **Single pair** — COVARIANCE.P returns 0 (single point, dx*dy=0,
   sum=0, cov=0/1=0). COVARIANCE.S returns `#DIV/0!` (n-1=0).
9. **Constant array** — both return 0 (dy=0 → sum_prod=0). UNLIKE
   CORREL which returns `#DIV/0!` for constant input (denom=0 in
   correlation formula). Verify this difference is documented.
10. **No numeric pairs** — both return `#DIV/0!`.
11. **Shape mismatch** — both return `#VALUE!` via `collect_xy_pairs`.
12. **Error propagation** — both propagate errors in either array.
13. **Arity** — both reject `args.len() != 2` with `#VALUE!`.
14. **Skip non-numeric pairs** — pair where EITHER side is non-numeric
    is dropped (matches CORREL canon).
