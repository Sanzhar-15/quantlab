## What to look for — classes of problems

### Correctness

1. **ISREF semantics:** verify the impl matches design § 2.3:
   - `ISREF(A1)` → TRUE.
   - `ISREF(A1:B3)` → TRUE.
   - `ISREF(SUM(...))` → FALSE in v1.
   - `ISREF(1+2)` / `ISREF(123)` / `ISREF("text")` → FALSE.
   - `ISREF(1/0)` → FALSE (NO eval; critical lazy-semantics).
   - `ISREF(#REF!)` → FALSE.
   - Arity → `#N/A`.
2. **`PlanKind::Function { returns_reference }` distinction:** v1 emits `returns_reference: false` unconditionally; impl returns FALSE. Does the test for `returns_reference: true` work as expected? (Test pins the future-correct path.)
3. **`ISREF(NamedRange)`:** how does the binder + lazy materializer treat a `NameRef → AggregateNameRef` plan? The lazy materializer's `AggregateNameRef` arm produces `PlanKind::RangeRef` → ISREF TRUE. Verify.
4. **ISFORMULA semantics** per design § 2.4:
   - Formula cell → TRUE.
   - Literal cell → FALSE.
   - Blank cell → FALSE.
   - Multi-cell range → `#N/A` (Microsoft canon; documented IronCalc divergence).
   - Non-reference scalar → `#N/A`.
   - `#REF!` arg → propagates.
   - Arity → `#N/A`.
5. **1×1 range handling:** ISFORMULA(A1:A1) — single-cell range. Treated as single-cell per design. Verify.
6. **Cross-sheet ISFORMULA:** `ISFORMULA(S1!A1)` → queries workbook on sheet 1. Verify cross-sheet ID flows correctly.
7. **Error class:** Microsoft canon for ISFORMULA non-reference → `#N/A`. IronCalc returns `#VALUE!`. v1 follows Microsoft. Verify by inspection.

### LazyShape dispatcher path

8. **ISREF dispatch flow:** `materialize_ref_arg_lazy(plan)` → `RefArg::Shape(PlanKind)`. Verify each `ExprPlan` variant maps correctly:
   - `CellRef` → `CellRef`.
   - `AggregateNameRef` / `RangeRef` / `StructuredRef` → `RangeRef`.
   - `Function { .. }` → `Function { returns_reference: false }` (v1).
   - `Number` / `Bool` / `String` / `Array` / `Binary` / `Unary` → `Literal`.
   - `Error` → `Error`.
9. **Critical: no eval under LazyShape.** Test `isref_of_divide_by_zero_returns_false_without_eval` is the load-bearing test. If it fails, the dispatcher regressed. Verify by tracing.
