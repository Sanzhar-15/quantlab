## 3. Batch 1 (4.10.A) — Logical fillins

### 3.1 Functions

#### `IFS(test1, value1, test2, value2, ..., [test_default, value_default])`

Multi-condition selector. Returns `valueK` for the first true `testK`. Excel canon:
- Variadic, even count of args (pairs of test+value).
- No `else` arg: if no test passes, return `#N/A`.
- Errors in tests propagate.
- Empty input → `#VALUE!`.
- Odd arg count → `#N/A` (matches Excel; the trailing unpaired arg is ignored as missing-value rather than syntax error).

```rust
pub fn ifs(args: &[Value]) -> Value {
    if args.is_empty() { return Value::Error(ErrorValue::Value); }
    let mut i = 0;
    while i + 1 < args.len() {
        match &args[i] {
            Value::Error(e) => return Value::Error(*e),
            other => match coercion::to_logical(other) {
                Ok(true) => return args[i + 1].clone(),
                Ok(false) => {}
                Err(e) => return Value::Error(e),
            },
        }
        i += 2;
    }
    Value::Error(ErrorValue::Na)
}
```

#### `IFNA(value, fallback)`

Like `IFERROR` but only catches `#N/A`. Other errors propagate.

```rust
pub fn ifna(args: &[Value]) -> Value {
    if args.len() != 2 { return Value::Error(ErrorValue::Value); }
    match &args[0] {
        Value::Error(ErrorValue::Na) => args[1].clone(),
        v => v.clone(),
    }
}
```

#### `XOR(args...)`

Variadic logical XOR — true iff an odd number of args are true. Mirrors `AND`/`OR` argument handling: skip blanks, coerce non-bool via `to_logical`, propagate errors, require ≥1 non-blank.

```rust
pub fn xor(args: &[Value]) -> Value {
    if args.is_empty() { return Value::Error(ErrorValue::Value); }
    let mut count = 0u64;
    let mut any_non_blank = false;
    for v in args {
        match v {
            Value::Error(e) => return Value::Error(*e),
            Value::Blank => {}
            other => {
                any_non_blank = true;
                match coercion::to_logical(other) {
                    Ok(b) => if b { count += 1 },
                    Err(e) => return Value::Error(e),
                }
            }
        }
    }
    if !any_non_blank { return Value::Error(ErrorValue::Value); }
    Value::Boolean(count % 2 == 1)
}
```

#### `SWITCH(expression, value1, result1, value2, result2, ..., [default])`

Matches `expression` against `valueK`. Returns `resultK` on first match. Optional trailing `default` (odd arg count after expression).

- Variadic ≥3 args (1 expression + at least 1 value+result pair).
- Even count after expression → no default → `#N/A` on no match.
- Odd count after expression → last arg is default.
- **Type-strict equality** per Excel canon + Codex HIGH-1 (verified against IronCalc `compare_values` at `.references/ironcalc/base/src/functions/util.rs:51` + Microsoft docs): `SWITCH(1, "1", "Text", 1, "Number")` returns `"Number"`. Number↔String never match.
- **Errors in `valueK` PROPAGATE** (Codex HIGH-1 correction; verified against IronCalc `.references/ironcalc/base/src/functions/logical/switch.rs:24`). My v1 draft had "skip errors" which was wrong.
- Errors in `expression` propagate.

```rust
pub fn switch(args: &[Value]) -> Value {
    if args.len() < 3 { return Value::Error(ErrorValue::Value); }
    let expr = &args[0];
    if let Value::Error(e) = expr { return Value::Error(*e); }
    let mut i = 1;
    while i + 1 < args.len() {
        let v = &args[i];
        let r = &args[i + 1];
        // Errors in case values PROPAGATE — IronCalc canon. Surfaces
        // before the no-match → #N/A path.
        if let Value::Error(e) = v { return Value::Error(*e); }
        if values_match_for_switch(expr, v) {
            return r.clone();
        }
        i += 2;
    }
    // i == args.len() - 1 → unpaired trailing arg is the default.
    if i < args.len() { return args[i].clone(); }
    Value::Error(ErrorValue::Na)
}
```

`values_match_for_switch`: case-insensitive String equality, Number bitwise-equal (NaN never matches NaN), Bool exact, Blank == Blank. **Number↔String cross-type never matches** (type-strict per Excel canon).

### 3.3 Test plan

Per function, the existing `scalar_fns::tests` module pattern:
- Happy path (2-3 cases).
- Error propagation (test in IFS, expression in SWITCH).
- Edge cases:
  - IFS: no match → #N/A; odd arg count → #N/A; first match wins.
  - IFNA: #N/A → fallback; other errors → propagate; non-error → value.
  - XOR: 0 / 1 / 2 / 3 trues; all blanks → #VALUE!.
  - SWITCH: no match + no default → #N/A; default branch; first match wins; type-strict equality.

Target: ≥6 tests per function, ≥24 total. Workspace test count: 2643 → ~2667.

Plus 1 e2e in `workbook_runtime::tests` exercising each through the full `set_formula` path.

## 4. Batches 4.10.B-G — brief outlines

### 4.10.B — Conditional aggregate fillins (MINIFS, MAXIFS, COUNTBLANK)

Mirror W5-55 SUMIFS/COUNTIFS pattern. All `RangeAwareFn`. COUNTBLANK is simpler (single range, count blanks). MINIFS/MAXIFS share W5-55's criterion-predicate suite + W5-61 wildcards. **W5-60 KNOWN DIVERGENCE** applies (sum_range vs range shape) — surface in matrix Notes.

### 4.10.C — Stats `*A` + info scalars (10 functions, expanded per Codex MEDIUM-2)

- **`*A` variants** (RangeAwareFn): AVERAGEA, MAXA, MINA. Coerce text → 0, bool → 0/1, error propagates. Distinct from base AVERAGE/MAX/MIN which skip text+bool.
- **Info scalars** (ScalarFn): NA, ERROR.TYPE, TYPE, ISEVEN, ISODD, ISNONTEXT, N.
  - `NA()` — returns `Value::Error(ErrorValue::Na)`. Arity 0.
  - `ERROR.TYPE(value)` — 1=#NULL!, 2=#DIV/0!, 3=#VALUE!, 4=#REF!, 5=#NAME?, 6=#NUM!, 7=#N/A. Non-error → #N/A.
  - `TYPE(value)` — 1=number, 2=text, 4=bool, 16=error, 64=array.
  - `ISEVEN(n)` / `ISODD(n)` — truncate toward zero; non-numeric → #VALUE!.
  - `ISNONTEXT(v)` — true unless value is a String.
  - `N(v)` — coerce to number: Number→same, Bool→0/1, Date→serial (existing date_system), String/Error→0, Blank→0.

Reference-tier (ISFORMULA, FORMULATEXT, ROW, COLUMN, ROWS, COLUMNS, ISREF) **moved to Wave 3** per Codex HIGH-2.

### 4.10.D — Math combinatorics + sum variants

- `FACT(n)` — factorial; n<0 → #NUM!; n>170 → #NUM! (overflow).
- `FACTDOUBLE(n)` — double factorial; same bounds.
- `COMBIN(n,k)`, `COMBINA(n,k)` — combinations (no rep / with rep).
- `PERMUT(n,k)`, `PERMUTATIONA(n,k)` — permutations.
- `SUMSQ` — variadic sum of squares (ScalarFn over scalar args; RangeAwareFn variant in follow-up if needed).
- `SUMX2MY2`, `SUMX2PY2`, `SUMXMY2` — paired array sum-of-squared-differences/sums. RangeAwareFn (two range args).

### 4.10.E — Text utility fillins

- `TEXTJOIN(delim, ignore_empty, args...)` — RangeAwareFn; supersedes CONCAT for delimiter-controlled join.
- `VALUE(text)` — text → number; **locale-aware** (decimal separator). ContextAwareFn (uses `EvalContext.locale`).
- `CHAR(code)`, `CODE(text)`, `UNICODE(text)`, `UNICHAR(code)` — codepoint round-trip. Scalar.
- `FIXED(number, decimals, no_commas)` — number → text with thousands grouping. **Locale-aware** (grouping separator).
- `DOLLAR(number, decimals)` — currency text. **Locale-aware** (currency symbol via locale config; for V1 use `$`).

### 4.10.F — Financial basics (expanded per Codex MEDIUM-1)

**TVM family** (all ScalarFn, share an internal `tvm_equation` helper per IronCalc's pattern):
- `PMT(rate, nper, pv, [fv], [type])` — payment per period.
- `FV(rate, nper, pmt, [pv], [type])` — future value.
- `PV(rate, nper, pmt, [fv], [type])` — present value.
- `NPER(rate, pmt, pv, [fv], [type])` — number of periods.
- `RATE(nper, pmt, pv, [fv], [type], [guess])` — iterative (Newton-Raphson, 50 iters, eps=1e-7 per IronCalc). Failure to converge → #NUM!.
- `IPMT(rate, period, nper, pv, [fv], [type])` — interest portion of period payment (added per Codex MEDIUM-1).
- `PPMT(rate, period, nper, pv, [fv], [type])` — principal portion of period payment (added per Codex MEDIUM-1).

**Sign convention** (verified via Codex against IronCalc + Microsoft): `pv*(1+rate)^nper + pmt*(1+rate*type)*[(1+rate)^nper - 1]/rate + fv = 0`. `type=0` end of period, `type=1` beginning. Nonzero `type` treated as begin.

**Cash-flow** (RangeAwareFn):
- `NPV(rate, value1, value2, ...)` — net present value. Variadic; mixes scalars + ranges.
- `IRR(values, [guess])` — internal rate of return. Iterative (Newton-Raphson + bisection fallback per IronCalc's `compute_irr`). Requires sign-change in values → otherwise #NUM!.

**XNPV / XIRR / MIRR** explicitly deferred to Wave 3 (date-indexed; need date arg handling).

### 4.10.G — XLOOKUP / XMATCH + ADDRESS

**XLOOKUP**(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode]):
- match_mode: 0=exact (default), -1=exact-or-next-smaller, 1=exact-or-next-larger, 2=wildcard.
- search_mode: 1=first→last (default), -1=last→first, 2=binary-asc, -2=binary-desc.
- Returns `lookup_array`-sized portion of `return_array` (V1: scalar return only; 2D return-array → Phase 4.7 spill).
- `if_not_found`: default `#N/A`.

**XMATCH**(lookup_value, lookup_array, [match_mode], [search_mode]) — like XLOOKUP but returns 1-based position.

**ADDRESS**(row_num, col_num, [abs_num=1], [a1=TRUE], [sheet_text]):
- abs_num 1-4 controls $ markers.
- a1=TRUE → A1; FALSE → R1C1.
- ContextAwareFn — needs workbook context for sheet name resolution + R1C1 formatting.

Reference-tier (ROW, COLUMN, ROWS, COLUMNS) **moved to Wave 3**.
